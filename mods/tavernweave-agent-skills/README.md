# TavernWeaveX

> 日本語版は claude-code-mods-ja プロジェクトによる翻訳です。原作者とライセンスは文末を参照してください。原文は [README.en.md](README.en.md) をご覧ください。

23 个共享技能，用于角色卡、软件工作与有界的云任务，带能力检查与可续接的交接；在 Claude Code 中注入 Host Front Door、添加 tavernweave agent，并在提示行上方提供 Soul 模式开关。实际执行取决于宿主工具与权限。

## 安装

```
/plugin install tavernweave-agent-skills@claude-code-mods-zh
```
