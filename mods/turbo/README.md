# turbo

> 日本語版は claude-code-mods-ja プロジェクトによる翻訳です。原作者とライセンスは文末に記載されています。

人がゲートを担うエージェントのソフトウェアファクトリーです。何を作るかと出来栄えの判定はあなたが行い、スキルが形にして構築・仕上げ・リリースし、そこから学習します。

## インストール

```
/plugin install turbo@claude-code-mods-ja
```
