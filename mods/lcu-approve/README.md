# lcu-approve

> 日本語版は claude-code-mods-ja プロジェクトが翻訳しました。原作者とライセンスは文末を参照してください。

Claude アプリおよび Claude Code における LCU のコンピューター操作に対して、アプリごとのネイティブな承認（今回のみ許可、常に許可、拒否）を提供します。`/computer-use-apps` で許可済みアプリのパネルを表示します。

## インストール

```
/plugin install lcu-approve@claude-code-mods-ja
```
