# lcu-approve

> 日本語版は claude-code-mods-ja プロジェクトによる翻訳です。原作者とライセンスは文末を参照してください。

为 Claude 应用与 Claude Code 中的 LCU 电脑操作提供按应用的原生授权（本次允许、始终允许、拒绝），并提供 `/computer-use-apps` 已授权应用面板。

## 安装

```
/plugin install lcu-approve@claude-code-mods-zh
```
