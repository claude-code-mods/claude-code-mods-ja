# Claude Code 原生プロンプト予測

> 日本語版は claude-code-mods-ja プロジェクトによる翻訳です。原作者とライセンスは文末を参照。原版 README は [README.en.md](README.en.md)。

本アダプターは Claude Code のネイティブ関数フック（function hooks）を使用します。Claude Code 2.1.310 に対して検証済みで、それより古いバージョンはサポート対象外です。新しいプロセスへの読み込みは `--plugin-dir <アダプターの絶対パス>` と `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1` で行います。アダプターを読み込んでも、ユーザーのグローバルな Claude 設定にはインストールされません。

ランチャーは `PEBREL_PREDICTION_ENDPOINT`（ポート付き HTTP IPv4 ループバックアドレス）、`PEBREL_PREDICTION_TOKEN`、および `CLAUDE_CODE_ENABLE_PROMPT_SUGGESTION=false` を提供する必要があります。最後の変数はそのプロセス内で Claude Code 組み込みの予測推論を抑制します。設定しないとアダプターは何もしません。同一ターンの完了に対して二重に推論リクエストが発生するのを避けるためです。グローバル設定や主モデルの設定は変更されません。

成功して完了した主ターンで、かつターミナルの入力欄が空でマウントされている場合のみが対象です。`$.session.messages()` がメモリ上のユーザー/アシスタントテキストを提供します。ツール呼び出しのペイロードは送信されません。ブリッジが受け取るのは最大 24 メッセージ、1 メッセージあたり最大 3000 UTF-16 ユニット、合計最大 12000 ユニットです。予測プロンプト、設定されたプロバイダー、言語、およびさらなるコンテキスト制限は Pebrel が所有します。アダプターは話し方スタイルのプロンプトも永続化も追加しません。

ローカライズされたブリッジ文案 `loading_text` は Claude Code の底部にある灰色の `PromptHint` に表示され、400 ms ごとに `.`、`..`、`...` と追加されます。編集不可で、`prompt.suggest` に送られることはありません。候補が完了するとネイティブの `$.prompt.suggest({text})` を呼び出すため、ネイティブの Tab/右矢印の動作で入力欄が埋められ、送信はされません。入力欄は常に Claude Code が所有します。

編集、プロンプト変更、新規ターン、セッション終了、および 10 秒の期限は、保留中の UI 作業を無効化します。すべての結果はリビジョン、セッション、空の下書きを再チェックします。ネイティブの `http.fetch` API には中止シグナルがありません。ここでの中止は古い結果を抑制するだけであり、ネットワーク/リクエストの期限はブリッジが所有します。予測 UI がアイドルのとき、ディスクのポーリングやタイマーは残りません。

動作契約の実行: `node --test tests/*.test.mjs`、実際の Claude スキャナー: `claude plugin validate --strict --json <アダプターディレクトリ>`。モックテストはネイティブターミナルの視覚的な受け入れや、未テストの Claude バージョンとの互換性を証明しません。
