# Firstmate Calm

> 日本語版は claude-code-mods-ja プロジェクトによる翻訳です。原作者とライセンスは文末を参照してください。

Firstmate Calm 为 Claude Code 带来帆船工作动画与会话专用转录展示，并与 Pi Calm 扩展共享每个 home 的 calm 偏好。

其 hooks 模块可通过 `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS` 或 Claude Code 的 tengu_plugin_hooks_modules 灰度开关加载，但仅当 `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS` 恰为 1 时才会生效，其余情况下完全不执行任何操作。

## 安装

```
/plugin install fm@claude-code-mods-zh
```
