# Firstmate Calm

> 日本語版は claude-code-mods-ja プロジェクトによる翻訳です。原作者とライセンスは文末に記載されています。

Firstmate Calm は、Claude Code に帆船の作業アニメーションとセッション専用のテキスト表示をもたらし、Pi Calm 拡張と home ごとの calm 設定を共有します。

この mod の hooks モジュールは `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS` または Claude Code の tengu_plugin_hooks_modules の段階的公開フラグで読み込まれますが、実際に有効になるのは `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS` がちょうど 1 の場合だけです。それ以外の場合は一切動作しません。

## インストール

```
/plugin install fm@claude-code-mods-ja
```
