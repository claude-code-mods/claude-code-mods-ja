# work-mode

> 日本語版は claude-code-mods-ja プロジェクトによる翻訳です。原作者とライセンスは文末を参照してください。

为 Claude Code 提供 `/work-mode` 会话模式：

- `auto`：不中途提问
- `out`：委派批量工作
- `wrap`：收敛并收尾

另外还提供一个委派提醒。

## 安装

```
/plugin install work-mode@claude-code-mods-zh
```
