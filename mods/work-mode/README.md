# work-mode

> 日本語版は claude-code-mods-ja プロジェクトによる翻訳です。原作者とライセンスは文末に記載されています。

Claude Code に `/work-mode` セッションモードを提供します：

- `auto`：途中で質問しない
- `out`：一括作業を委任する
- `wrap`：収束して仕上げる

さらに、委任を促すリマインダーもあります。

## インストール

```
/plugin install work-mode@claude-code-mods-ja
```
