# ripple

> 日本語版は claude-code-mods-ja プロジェクトによる翻訳です。原作者とライセンスは文末を参照してください。原文は [README.en.md](README.en.md) をご覧ください。

为每条提示选择推理强度、为每个委派任务选择 worker，可保持提示词缓存温热，并显示 ClaudeRipple 把每个请求发往何处。

## 安装

```
/plugin install ripple@claude-code-mods-zh
```
