# ripple

> 日本語版は claude-code-mods-ja プロジェクトが翻訳しました。原作者とライセンスは文末を参照してください。原版の README は [README.en.md](README.en.md) を参照してください。

プロンプトごとに推論強度を、委譲タスクごとに worker を選択できます。プロンプトキャッシュを温かく保ち、ClaudeRipple が各リクエストをどこへ送るかを表示します。

## インストール

```
/plugin install ripple@claude-code-mods-ja
```
