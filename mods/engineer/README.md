# engineer

> 日本語版は claude-code-mods-ja プロジェクトが翻訳しました。原作者とライセンスは文末を参照してください。原版の README は [README.en.md](README.en.md) を参照してください。

DAE（Disciplined Agent Engineering：厳密なエージェント工学）のツールキットです。要件の受付、受け入れ基準の洗い出し、仕様の記述、計画、実装、検証、強化まで、DAE のプロセスを Claude Code で実行するためのスキルを提供します。

## インストール

```
/plugin install engineer@claude-code-mods-ja
```
