# claude-carbon

> 日本語版は claude-code-mods-ja プロジェクトによる翻訳です。原作者とライセンスは文末に記載されています。原版の README は [README.en.md](README.en.md) をご覧ください。

ターミナルと Claude デスクトップアプリで、Claude Code セッションのカーボンフットプリントを追跡します。

## インストール

```
/plugin install claude-carbon@claude-code-mods-ja
```
