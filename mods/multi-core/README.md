# multi-core

> 日本語版は claude-code-mods-ja プロジェクトが翻訳しました。原作者とライセンスは文末を参照してください。原版の README は [README.en.md](README.en.md) を参照してください。

1 つの Claude Code セッションで ChatGPT (Codex)、Cursor、OpenCode Zen、Antigravity のモデルを使用できます。`/model` で切り替え、名前付きのネイティブ worker に委譲し、各プロバイダー独自のログインと権限を保持します。

## インストール

```
/plugin install multi-core@claude-code-mods-ja
```
