# claude-council

> 日本語版は claude-code-mods-ja プロジェクトによる翻訳です。原作者とライセンスは文末に記載されています。原版の README は [README.en.md](README.en.md) をご覧ください。

複数の AI エージェント（Gemini、OpenAI、Grok、Perplexity、Kimi、OpenRouter 経由の任意のモデル、インストール済みの codex、antigravity、grok、kimi、cursor CLI、ローカルの ollama モデル）に同じ質問を同時に投げかけ、プログラミングの問題に対する多様な視点を得る Claude Code プラグインです。tmux または Claude Code 内にストリーミングパネルを表示し、有効にするとプロンプト行の上に追加のレビュー用の一行を表示します。

## インストール

```
/plugin marketplace add hex/claude-council
/plugin install claude-council@claude-council
```
