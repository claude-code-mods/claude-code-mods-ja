# shared-session

> 日本語版は claude-code-mods-ja プロジェクトによる翻訳です。原作者とライセンスは文末を参照してください。原文は [README.en.md](README.en.md) をご覧ください。

用链接或团队共享 Claude Code 会话：队友从自己的 Claude Code 加入并交谈；一个会话完成工作，所有人实时看到每一轮，宿主机批准在其机器上运行的内容。

## 安装

```
/plugin install shared-session@claude-code-mods-zh
```
