# shared-session

> 日本語版は claude-code-mods-ja プロジェクトが翻訳しました。原作者とライセンスは文末を参照してください。原版の README は [README.en.md](README.en.md) を参照してください。

リンクやチームで Claude Code セッションを共有できます。チームメイトが各自の Claude Code から参加して会話します。1 つのセッションが作業を進め、全員が各ターンをリアルタイムで見守り、ホストが自分のマシン上で実行される内容を承認します。

## インストール

```
/plugin install shared-session@claude-code-mods-ja
```
