# storybloq

> 日本語版は claude-code-mods-ja プロジェクトによる翻訳です。原作者とライセンスは文末を参照してください。翻訳元は中国語の README です。

Claude Code と Codex 向けのプロジェクトメモリです。チケット、問題、引き継ぎ、経験をリポジトリ内の `.story/` ディレクトリに保存します。

## インストール

```
/plugin install storybloq@claude-code-mods-ja
```
