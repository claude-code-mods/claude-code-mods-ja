# caliber-jev-compaction

> 日本語版は claude-code-mods-ja プロジェクトによる翻訳です。原作者とライセンスは文末に記載されています。

Claude Code のセッションに対して、逐語的に保持する Jev コンパクションを提供します。

## インストール

```
/plugin install caliber-jev-compaction@claude-code-mods-ja
```

インストール後、プラグインの設定に自分の TypeSafe API key を入力できます。
